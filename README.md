# Proyecto de ficheros y excepciones

Aplicación de consola en C# para registrar y consultar gastos guardados en `gastos.csv`.

## Requisitos

- .NET 10 SDK

## Ejecutar

Desde la carpeta del proyecto:

```bash
dotnet run
```

El archivo `gastos.csv` se crea en el directorio de trabajo al añadir el primer gasto. Se mantiene local y no se incluye en el repositorio.
